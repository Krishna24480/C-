⭐ Priority

If you want the minimum STL that makes you genuinely comfortable, focus heavily on:

vector → string → pair → iterators → algorithms → stack → queue → priority_queue → set → map → unordered_set → unordered_map → lambdas → custom comparators.

Once you can use those without constantly looking up syntax, you can handle a very large portion of everyday C++ and DSA work.
